# Full Adder Design using Vivado

## Overview

This project implements a 1-bit Full Adder using Verilog HDL and simulates its functionality using Xilinx Vivado.

A Full Adder is a combinational circuit that performs the addition of three binary inputs: A, B, and Carry-In (Cin). It produces two outputs: Sum and Carry-Out (Cout).

---

## Objectives

- Design a 1-bit Full Adder using Verilog HDL
- Verify its functionality through simulation
- Analyze Sum and Carry outputs for different input combinations

---

## Tools Used

- Xilinx Vivado

---

## Inputs and Outputs

### Inputs

- A
- B
- Cin (Carry-In)

### Outputs

- Sum
- Cout (Carry-Out)

---


## Design Flow

1. Created the Full Adder module in Verilog.
2. Developed a testbench to verify functionality.
3. Simulated the design using Vivado.
4. Verified the Sum and Carry outputs.

---

## Simulation Results

The simulation verified the correct operation of the Full Adder for all possible input combinations.
